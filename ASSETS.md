# Asset provenance

The repository includes optimised copies of every photograph used by the website. Original source JPEGs remain in the source workspace’s `Images` folder and were not modified.

## Official branding

`logo.webp` is a resized copy of `WhatsApp Image 2026-10-28 at 15.14.58.jpeg`.
`monogram.webp` is a crop of that same official image. No new logo was designed.

## Generated editorial visuals

Generated with the image-generation tool, referencing the official Blissworld logo:

- `everyday-pair.webp`: burgundy handbag + ivory bottle concept, gold brand details.
- `ivory-bottle.webp`: crop of the generated everyday-pair image.
- `school-pair.webp`: lavender/ivory backpack + bottle concept, gold branding.
- `dining-set.webp`: blush/ivory plate, bowl and cutlery concept, gold branding.
- `cocoa-editorial.webp`: promotional edit referencing the supplied cocoa tracksuit and official logo, adding a small gold embroidered mark and a styled setting. Used as an editorial, not as an original product photograph.

Generated source PNGs remain in the desktop app’s generated-images folder. The project contains independent WebP copies of all images it uses.
